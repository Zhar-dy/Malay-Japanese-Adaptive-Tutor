RAG Prototype Dependencies
The runtime prototype uses the Python 3.10+ standard library (sqlite3, urllib, json, math) and communicates directly with a local Ollama daemon.

Runtime requirements:
- Python >= 3.10
- Ollama (https://ollama.com)
- embeddinggemma:300m
- qwen3.5:4b

Optional test runner (built-in unittest is also supported):
pytest>=8.0.0
